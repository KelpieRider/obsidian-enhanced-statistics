# 字数统计增强（Word Count+）

一个轻量的 Obsidian 字数统计插件，默认显示在右下角状态栏。

## 功能

- 在“单独字数”和“千字”之间切换：
  - `31,800词 · 56,300字符`
  - `31.8千词 · 56.3千字符`
- 编辑时只记录内容变化，不逐键扫描全文。
- 默认每 15 秒统计一次，可在设置中修改。
- 在设置页输入刷新秒数后，点击“刷新并应用”立即生效。
- 点击状态栏，或执行命令“切换字数显示方式（单独字数 / 千字）”，可快速切换显示方式。

字符数包含标点、Markdown 符号等非空白字符；词数按 CJK 单字和连续字母/数字统计。

## 安装

### 社区插件

在 Obsidian 的“设置 → 社区插件”中搜索“字数统计增强”。

### 手动安装

将 `main.js`、`manifest.json` 和 `styles.css` 放入：

```text
你的仓库/.obsidian/plugins/enhanced-word-count/
```

然后在 Obsidian 的“设置 → 社区插件”中启用插件。
