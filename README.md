# Valar的样式增强

一个轻量的 Obsidian 插件：在状态栏统计字数和字符数，统计一至五级标题，并支持文件目录长文件名自动换行，以及右键标题快速复制章节地址。

## 功能

- 字数统计：在「单独字数」和「千字」之间切换。
  - `31,800词 · 56,300字符`
  - `31.8千词 · 56.3千字符`
- 标题统计：统计当前页面的一至五级标题数量，例如 `标题 0/0/0`；页面使用四级或五级标题时继续显示对应级别，可在设置中关闭。
- 文件目录换行：长文件名、文件夹名自动换行显示完整内容，可在设置中调整阈值和重命名时的行为。
- 获取章节地址：在编辑、实时预览或源码模式下右键某个标题，选择「获取章节地址」，把 `文件夹名.文件名.一级标题.二级标题.三级标题` 复制到剪贴板。
- 编辑时只记录变化，按设定的间隔（默认 15 秒）重新统计，不逐键扫描全文。
- 点击状态栏，或执行命令「切换字数显示方式（单独字数 / 千字）」，可快速切换显示方式。

## 安装

手动安装：把 `main.js`、`manifest.json` 和 `styles.css` 放入：

```text
你的仓库/.obsidian/plugins/valar-style-enhancement/
```

然后在 Obsidian 的「设置 → 第三方插件」中启用。
